# 출시 안내서: 구글 플레이부터

걸음모도로는 웹앱이라 지금도 휴대폰 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.
여기서는 한 걸음 더 나아가 **구글 플레이 스토어**에 올리는 순서를 정리했어요.
결제나 계정 등록처럼 본인만 할 수 있는 일에는 🙋 표시를 붙였어요.

---

## 0단계. 지금 바로 되는 것 (이번 업데이트)

- 개인정보처리방침 `/privacy`, 이용약관 `/terms` 페이지 (스토어 등록에 필수)
- 설정 → 계정 → **계정 삭제** (구글 플레이는 계정을 만드는 앱에 이 기능을 요구해요)
- 앱 설치용 서비스 워커 `/sw.js` (인터넷이 잠깐 끊겨도 첫 화면이 열려요)
- 플레이 앱 연결 파일 `/.well-known/assetlinks.json` (환경변수를 넣으면 자동으로 채워져요)

---

## 1단계. 서버를 '잠들지 않게' 하기 🙋

Render 무료 요금제는 15분 동안 아무도 안 쓰면 서버가 잠들어서, 다음 사람이 열 때 **50초쯤** 기다려야 해요.
스토어 심사자나 첫 사용자가 그걸 보면 앱이 고장 난 줄 알아요.

1. Render 대시보드 → walkmodoro 서비스 → **Settings → Instance Type** → `Starter`(월 7달러)로 바꿔요.
2. (권장) 내 도메인 연결: 도메인 업체(가비아, Cloudflare 등)에서 주소를 사고(1년 1~2만 원),
   Render → **Settings → Custom Domains → Add**에 입력한 뒤 안내대로 DNS를 넣어요.
   - 도메인을 바꾸면 **카카오·구글 로그인 설정의 Redirect URI**에도 새 주소를 추가해야 해요
     (`https://새도메인/auth/kakao/callback`, `https://새도메인/auth/google/callback`).
3. Render → **Environment**에 `CONTACT_EMAIL`(문의 받을 이메일)을 넣어요. 약관 페이지에 보여요.

### 로그인 마무리 점검 🙋
- **Google Cloud → OAuth 동의 화면 → 게시 상태**가 '테스트'면 등록한 테스트 사용자 100명만 로그인돼요.
  **'앱 게시'**를 눌러 '프로덕션'으로 바꿔 주세요. (이름·프로필만 받으니 별도 심사 없이 바로 돼요)
- 동의 화면의 개인정보처리방침 링크에 `https://내주소/privacy`를 넣어요.

## 2단계. 구글 플레이 개발자 계정 🙋

1. https://play.google.com/console 에서 개발자 계정을 만들어요. **등록비 25달러(한 번만)**.
2. 신분 확인을 마쳐요(며칠 걸릴 수 있어요).
3. ⚠️ **개인 계정**은 정식 출시 전에 **테스터 12명 이상이 14일 동안 비공개 테스트**를 해야 해요.
   친구·가족에게 미리 부탁해 두면 좋아요.

---

## 3단계. 안드로이드 앱 파일 만들기 (코딩 없이)

웹앱을 그대로 감싸는 'TWA'라는 방식을 써요. **PWABuilder**가 대신 만들어 줘요.

1. https://www.pwabuilder.com 에 내 앱 주소(`https://내주소`)를 넣고 **Start**.
2. **Package For Stores → Android → Generate Package**.
   - Package ID: 예) `com.내이름.walkmodoro` (한 번 정하면 못 바꿔요)
   - App name: `걸음모도로`
   - Signing key: **Create new** 그대로 두기
3. 받은 zip 안에는 `.aab`(플레이에 올릴 파일), **서명 키(signing.keystore)와 비밀번호 파일**,
   `assetlinks.json`이 들어 있어요.
   - 🔐 **서명 키와 비밀번호는 잃어버리면 앱을 다시는 업데이트할 수 없어요.** 안전한 곳에 꼭 백업하세요.
     (채팅이나 GitHub에는 절대 올리지 마세요)
4. zip의 `assetlinks.json`을 열어 두 값을 Render **Environment**에 넣어요.
   - `ANDROID_PACKAGE` = `package_name` 값
   - `ANDROID_SHA256` = `sha256_cert_fingerprints` 안의 값 (`AA:BB:...` 형태)
5. 브라우저에서 `https://내주소/.well-known/assetlinks.json` 을 열어 값이 보이면 성공이에요.
   이게 맞아야 앱 위쪽에 주소창이 안 보이고 진짜 앱처럼 열려요.

---

## 4단계. 플레이 콘솔에 등록

1. **앱 만들기** → 이름 `걸음모도로`, 기본 언어 한국어, 앱, 무료.
2. **테스트 → 비공개 테스트** 트랙을 만들고 `.aab`를 올려요. 테스터 이메일을 추가해요.
3. ⚠️ 올린 뒤 **설정 → 앱 무결성 → 앱 서명**에 나오는 'SHA-256 인증서 지문'을 복사해서
   Render의 `ANDROID_SHA256`에 **쉼표로 이어 붙여요**. (예: `원래값,플레이값`)
   구글이 앱에 다시 서명하기 때문에 두 지문이 모두 필요해요.
4. **스토어 등록정보**
   - 짧은 설명(80자): `집중한 만큼 내 캐릭터가 지도 위를 걸어가는 귀여운 뽀모도로 타이머`
   - 아이콘 512×512: `app/static/icons/icon-512.png`
   - 그래픽 이미지 1024×500, 휴대폰 스크린샷 2장 이상 (필요하면 만들어 드릴게요)
5. **앱 콘텐츠**
   - 개인정보처리방침: `https://내주소/privacy`
   - 계정 삭제 URL: `https://내주소/privacy` (4번 항목에 삭제 방법이 있어요)
   - 광고: 없음 / 콘텐츠 등급 설문: 폭력·도박 등 모두 '아니요'
   - **데이터 보안** 설문 답안:

| 질문 | 답 |
| --- | --- |
| 데이터를 수집하나요? | 예 |
| 위치 | 대략적·정확한 위치, 앱 기능용, 선택 사항(권한 거부 가능), 공유 안 함 |
| 개인 정보 | 이름(닉네임), 사용자 ID, 계정 관리용, 선택 사항(로그인 안 해도 됨) |
| 앱 활동 | 기타 사용자 생성 콘텐츠(집중 기록), 앱 기능용 |
| 전송 중 암호화 | 예 (https) |
| 삭제 요청 가능 | 예 (설정 → 계정 삭제) |

6. 14일 테스트가 끝나면 **프로덕션 → 출시 신청**. 심사는 보통 며칠 걸려요.

## 나중에: 애플 앱스토어와 결제

- **앱스토어(아이폰)**: 연 99달러에 Mac이 필요하고, 애플은 웹사이트를 감싸기만 한 앱을 자주 거절해요(심사 지침 4.2).
  플레이 반응을 보고, 알림·위젯 같은 앱다운 기능을 더해서 도전하는 걸 추천해요.
  그동안 아이폰 사용자는 사파리 → 공유 → **홈 화면에 추가**로 쓸 수 있어요.
- **결제(프리미엄 아이템)**: 플레이 앱 안에서 디지털 아이템을 팔 때는 **구글 플레이 결제**를 써야 해요.
  TWA에서는 'Digital Goods API'로 붙일 수 있고, 아이템 목록은 이미 `app/avatar.py`의 `premium` 표시로 준비돼 있어요.
